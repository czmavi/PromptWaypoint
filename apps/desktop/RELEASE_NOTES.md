# Prompt Waypoint 0.2.0 for macOS

- Direct distribution for Apple Silicon and Intel Macs, macOS 13.3 or later.
- Start the bundled Local Agent from Settings. Deno is no longer needed for the
  installed app.
- Check for updates in the app and install a signed update with a restart.
- Updates wait until managed tasks have finished or have been stopped.
- Project folder picker and local provider profile discovery.

Codex CLI or Claude Code still needs to be installed and signed in separately.
