# macOS TestFlight discontinued

Prompt Waypoint for macOS is now distributed directly as a signed, notarized DMG
with updates hosted on GitHub Releases. See [DISTRIBUTION.md](DISTRIBUTION.md)
for installation, migration, signing and publishing.

Version 0.1.0 build 1 was previously uploaded to TestFlight under bundle ID
`com.caretsix.aiproductmanager`. That build is historical; this repository no
longer contains a macOS App Store build/export workflow. iOS still uses its own
App Store/TestFlight workflow.
